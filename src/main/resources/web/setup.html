Admin Panel · First-run setup

Local setup only. Enter the one-time token printed in the Minecraft server console. Nothing becomes public until you restart the server.

Setup authorization

Web server

Use a reverse proxy with HTTPS for remote access. Register the OAuth redirect as {origin}/api/auth/discord/callback.

Discord login

The secret is saved to the local server config. Protect that file and never commit it.

Ranks & permissions

Highest matching rank wins. Move ranks up/down to set precedence, and add or remove ranks as needed. Only ranks named dev or owner with admin access can open Access Manager.
